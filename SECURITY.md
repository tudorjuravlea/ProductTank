# Security

This is a local tool: it reads files you give it and renders them with a pinned Chromium. It makes
no network calls except the optional Figma capture tool, which you run yourself with your own token.

If you find something that leaks data or runs code it should not, open a private security advisory
on GitHub (Security tab, "Report a vulnerability") rather than a public issue. Include the command
you ran and what you saw.
